# Multi-Resource Slot Management SaaS API 🗓✨

Высокозагруженный B2B API-first микросервис на **Java 17 / Spring Boot 3** для квантования тайм-слотов, бронирования цепочек зависимых мульти-ресурсов и управления сложными графиками в распределенных системах.

## 🚀 Какую проблему решает?
Обычные календари (Calendly, Google Calendar, Yclients) созданы для записи к **одному** конкретному мастеру или ресурсу. Они ломаются, когда бизнесу нужно забронировать **цепочку зависимых ресурсов** одной атомарной транзакцией.

**Пример из медицины:** Запись пациента на МРТ с контрастом требует одновременного наличия свободного Врача + свободного Кабинета + свободного Томографа. Если хотя бы один компонент занят, тайм-слот выдаваться не должен. Данный сервис берет всю сложную интервальную математику на себя.

## 🛠 Технологический стек и Архитектура
* **Backend:** Java 17, Spring Boot 3.3+, Spring Data JPA.
* **Database:** PostgreSQL.
* **Migrations:** Liquibase (SQL-formatted).
* **Security & Multi-tenancy:** Изоляция данных компаний по API-ключам (Bearer Token) через HandlerInterceptor.
* **DTO Layer:** Полное разделение сущностей БД и объектов передачи данных (Lombok).

## ⚡️ Ключевые фичи
1. **Абсолютная защита от Race Condition:** Нарезка слотов и пессимистические блокировки строк `FOR UPDATE` (`@Lock(LockModeType.PESSIMISTIC_WRITE)`) на уровне БД. Ситуация двойного бронирования исключена.
2. **Сложные графики и ночные смены:** Поддержка разделенного рабочего дня (перерывы, обеды, сиесты) и ночных смен на базе алгоритма *Midnight Splitting* (автоматическое дробление интервалов по границе суток).
3. **UTC под капотом:** Хранение рабочих интервалов в локальном времени объекта (`LocalTime` + `Timezone ID`), но расчет слотов и транзакции строго в абсолютных координатах `OffsetDateTime` (UTC).

## 💻 Быстрый старт (Локально)

1. Создайте пустую базу данных в PostgreSQL с именем `slots_db`.
2. Откройте `src/main/resources/application.yml` и укажите ваши `username` и `password` от базы.
3. Запустите приложение через вашу IDE или консоль:
   ```bash
   mvn spring-boot:run
   ```
   Liquibase автоматически накатает схему таблиц и необходимые индексы.

## 🔐 Инициализация тестовой компании
Для тестирования b2b-изоляции выполните SQL-запрос в вашей БД для создания тестового окружения:
```sql
INSERT INTO companies (id, name) VALUES (1, 'Клиника Мед-Эксперт');
INSERT INTO api_keys (key_token, company_id, is_active) VALUES ('sk_test_token_42', 1, true);
```
Во все последующие HTTP-запросы передавайте заголовок: `Authorization: Bearer sk_test_token_42`.
